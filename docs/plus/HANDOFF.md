## 1) المشروع والمالك وطريقة العمل
- **Nuvio Plus**: نسخة أندرويد معدّلة من Nuvio Mobile بميزات خاصة (ترجمات عربية ومخصصة، تنزيل المواسم، مجلد تنزيل SAF، تحديث داخلي…).
- المالك: **محمد**، غير تقني. **الرد بالعربية دائمًا**، مختصر ومباشر بعناوين ونقاط، المخرجات الملفية بصيغة HTML. Claude ينفّذ كل العمل التقني ويشرحه ببساطة.
- **تقسيم الأدوار**: Claude = تنفيذ وPRs وCI. ChatGPT = تصميم ومراجعة (لا يعدّل GitHub؛ المالك ينقل ملاحظاته). المالك = القرارات عالية الخطورة والنشر النهائي فقط.
- **صلاحية التنفيذ المستقل (Build 15)**: افحص، افتح فروعًا، أصلح، اختبر، وادمج PR **فقط إذا نجحت كل فحوصه**، دون سؤال. اطلب موافقة المالك فقط عند:
  1. تغيير هوية التطبيق أو مفاتيح التوقيع.
  2. احتمال فقد بيانات المستخدمين أو أي إجراء غير قابل للتراجع.
  3. تغيير جوهري خارج نطاق Build 15.
  4. النشر الإنتاجي النهائي.
- **استثناء قائم**: PR #28 (إيقاف حلقات الموسم) **لا يُدمج قبل أن يراجع المالك تقرير الحالات**.

## 5) مشكلة إيقاف حلقات الموسم (PR #28، B15-DL-03)
**المشكلة المثبتة**:
- `SeasonQueuePolicy.busy()` كان يحسب الحلقة المتوقفة «مشغولة»، فتتوقف كل حلقات الملف الشخصي.
- لم يكن في التطبيق «إيقاف موسم» ولا «إيقاف الكل».
- استئناف حلقة متوقفة أثناء عمل الطابور كان يبدأ تنزيلًا ثانيًا متزامنًا.

**العقد المتفق عليه**:
1. إيقاف حلقة واحدة: تُتجاوز وتكمل الحلقات المؤهلة التالية. تحتفظ بمكانها وملفها الجزئي، ولا تُعاد محاولتها تلقائيًا، ولا يُستبدل ملفها أو يُحذف.
2. استئنافها أثناء تنزيل آخر: حالة `Resuming`. تنتظر دورها ثم تكمل **نفس التنزيل**، دون تنزيل متزامن إضافي ودون إيقاف التنزيل الجاري.
3. إيقاف موسم: يمنع ذلك الموسم فقط.
4. إيقاف الكل: يوقف كل تنزيلات الملف الشخصي ولا يبدأ شيئًا جديدًا حتى «استئناف الكل».
5. «استئناف الكل» و«استئناف الموسم» يستأنفان فقط ما أوقفاه (`pausedBy`)، لا ما أوقفه المستخدم فرديًا.
6. NeedsChoice يُتجاوز ويبقى سببه ظاهرًا.
7. تبقى قواعد Wi-Fi والملفات الشخصية وSAF وقيود Android 14 للخلفية كما هي.

**التنفيذ**:
- `SeasonDownloadQueue.kt` و`SeasonQueueStorage.kt`.
- `DownloadsRepository.resumeDownload(fromQueue)`.
- مستقبل إشعار الاستئناف يمر بـ`holdResume`.
- `DownloadsTransferJobService.chainStepAfter`.
- واجهة التنزيلات: إيقاف/استئناف الكل، وإيقاف/استئناف لكل موسم.
- التخزين متوافق مع Build 12–14:
  - الحقلان الجديدان `pausedBy` و`resuming` إضافيان على الشكل القديم `Downloading` + `paused`.
  - حالات الإيقاف الجماعي مخزنة تحت مفتاح جديد `season_queue_holds`.

**شروط قبول #28**:
- [ ] نجاح «Nuvio Plus checks» كاملًا:

## 7) المحظورات (ثابتة)
- لا Force Push، ولا تجاوز لأي فحص أو حماية، ولا تعطيل أو حذف لاختبار فاشل، ولا استثناءات صامتة لإظهار نتيجة خضراء.
- لا دمج لـPR فيه فحص فاشل حتى لو بدا الفشل خارجيًا: أعد التشغيل أو أصلح السبب.
- لا تغيير لهوية الحزمة أو التوقيع أو بوابات الإصدار. لا كشف للمفتاح أو كلمة المرور في السجلات أو المستودع. لا طلب للأسرار في المحادثة. لا نقل للأسرار إلى بيئة بناء كود غير موثوق.

- لا فقد لبيانات المستخدمين:
  - لا تغيير صيغة تخزين بشكل لا تقرؤه Build 12–14.
  - لا حذف لملفات جزئية أو تنزيلات.
  - لا حذف لسجلات فشل أو ملفات APK أو فروع دون التحقق من أثر ذلك.
